§ 01新增專案

Projects 面板的新增專案流程：資料夾選擇器依平台挑選，找不到對話框時改輸入路徑

原本按下新增專案只會呼叫 /usr/bin/osascript，Linux 上直接出現 Folder picker failed；現在 window.luau 先判斷是否為 macOS，其餘依序嘗試 zenity、kdialog，兩者都沒有時改在面板上輸入絕對路徑。

🎯 核心必看 (1)

1以 /usr/bin/osascript 是否存在判斷 macOS，再依序找 zenity 與 kdialog

2兩種對話框工具都沒有時，改在面板上請使用者輸入絕對路徑

3取消不再顯示錯誤：AppleScript 回 -128，zenity 與 kdialog 回 1

§ 02外部指令

worktrunk.luau 的外部指令啟動：bash、sleep、pwd、kill 與 tern 改為先查 PATH 再退到絕對路徑

原本多處直接寫死 /bin/bash、/bin/sleep、/bin/pwd、/bin/kill 與 Tern.app 內的 tern 路徑，PATH 稀疏或沒有 /bin 的系統會啟動失敗；現在統一由 worktrunk.luau 的 platform_tool 解析，其他檔案只呼叫它。

🎯 核心必看 (4)

1新增 platform_tool，並以它提供 tern_binary、bash 與 sleep

2worktrunk.luau 自己的指令改用解析後的 bash 與 pwd

3intercom.luau、omplink.luau 與 window.luau 改呼叫新 helper

§ 03worktree 操作腳本

worktree-operation.sh 的收據寫入與清理：mktemp、mv、rm 改為先用 command -v 找路徑

建立與刪除 worktree 的腳本原本固定呼叫 /usr/bin/mktemp、/bin/mv、/bin/rm；現在開頭先用 command -v 從 PATH 找，找不到才退回原本的絕對路徑。

🎯 核心必看 (1)

1腳本開頭先解析 mktemp_cmd、mv_cmd 與 rm_cmd

2收據暫存檔的建立、改名與清理都改用解析後的變數

§ 04版本與文件

README、AGENTS.md、CHANGELOG 與 plugin.toml：平台標示與前置需求改為 macOS 與 Linux，版本升到 2.4.0

原本文件仍寫 macOS only，plugin.toml 停在 2.3.3；現在 README 與 AGENTS.md 說明 Linux 的選擇器、快捷鍵與安裝方式，CHANGELOG 新增 2.4.0 條目，plugin.toml 升版。

🎯 核心必看 (4)

1plugin.toml 升到 2.4.0，CHANGELOG 新增 2.4.0 條目

2README 與 AGENTS.md 的平台標示、前置需求與已知限制改為 macOS 與 Linux

§ 05決策與任務紀錄

DECISIONS.md 與 .tasks 任務紀錄：留下不加建置步驟、選擇器方案與快捷鍵的取捨

Linux 支援牽涉不加建置步驟、選擇器方案與快捷鍵等取捨，原本沒有地方可查；現在 DECISIONS.md 記錄採用與否決的理由，.tasks 下的 TASK.md 附上驗收清單與本機端到端實測證據。
